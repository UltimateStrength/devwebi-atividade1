# Atividade 1 de Desenvolvimento Web I
## IFPR | Análise e Desenvolvimento de Sistema

### Sobre a atividade:
- Fazer um site sobre um país, cidade ou lugar
- No mínimo 5 páginas
- Uso de links entre páginas e links externos
- Pelo menos uma página sobre os pontos turísticos
- Pelo menos uma página sobre as comidas típicas
- Uso de Imagens
- Adicione DIVs
- Faça uso correto de Classes e Ids
- Utilizar propriedades css e tags HTML vistas
- A avaliação da estética do site será subjetiva, analisando o esforço empregado e a
organização do código.
